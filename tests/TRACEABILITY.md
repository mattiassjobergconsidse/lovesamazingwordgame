## Requirements without an automated test

These are rules about how the code is written, not behaviour a test can observe. Each is enforced by tooling or reviewed in the NH-19 gate (see the `codereview_*.md` files).

| Requirement             | How it is checked                                                                                                    |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------- |
| FR-BP-1, FR-BP-8        | `npm run lint` (typed `strictTypeChecked` rules, zero warnings); a grep for `as`, `!`, `any` and `eslint-disable`    |
| FR-BP-3                 | `npm run build`; `import.meta.env.BASE_URL` for assets; the base path appears only in `vite.config.ts`               |
| FR-BP-5                 | Review of the CSS; `prefers-reduced-motion` branches are covered by the mode tests                                   |
| FR-BP-6, FR-TEST-1 to 7 | Review of the test suite; `npm run test:coverage` with the thresholds in `vite.config.ts`                            |
| FR-BP-7                 | Review: TSDoc on exported symbols in `core/`, `storage/` and `hooks/`                                                |
| FR-BP-9                 | `.github/workflows/deploy.yml` (least-privilege permissions, `npm ci`, pinned major versions)                        |
| FR-BP-10                | Git history and pull requests                                                                                        |
| FR-LANG-1, FR-LANG-2    | `.gitattributes`; a scan for BOM, CRLF and Swedish text outside `src/i18n/sv.ts` and `src/data/`                     |
| FR-THEME-2              | Colour tokens in `src/index.css`; visual check in every theme                                                        |
| FR-WR-5                 | Out of scope for v1 by decision                                                                                      |
| NH-19                   | This gate itself; results in `codereview_security.md`, `codereview_code_quality.md` and `codereview_architecture.md` |

Requirements not listed in either table have not been implemented yet.
