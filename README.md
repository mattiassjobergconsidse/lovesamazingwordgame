# Love's Amazing Word Game

A web app for learning Swedish to English vocabulary ("glosor"). Create or import word lists,
practise them in quiz mode and let spaced repetition focus on the words you find hard.
All data stays in your browser. No accounts, no backend.
Live: https://mattiassjobergconsidse.github.io/lovesamazingwordgame/

## Tech stack

TypeScript, React, Vite, IndexedDB (idb), Vitest, GitHub Actions + GitHub Pages.

## Development

```powershell
npm install
npm run dev      # http://localhost:5173/lovesamazingwordgame/
npm run lint
npm run build
```
